# FTC TeleOp Robot Control System

Sistema de controle teleoperado desenvolvido em Java para robô de competição da FIRST Tech Challenge (FTC), utilizando o FTC SDK para controle de movimentação, garra e servo contínuo em tempo real.

## Sobre o Projeto

Este projeto foi desenvolvido para controle de um robô utilizado em competições de robótica FTC (FIRST Tech Challenge). O sistema permite a movimentação omnidirecional do robô através de controle via gamepad, além do acionamento de mecanismos auxiliares como garra motorizada e servo contínuo.

O código foi baseado em um template do FTC SDK e adaptado conforme as necessidades do robô da equipe, incluindo implementação e ajustes da lógica de movimentação e controle dos mecanismos.

---

## Funcionalidades

- Controle de movimentação omnidirecional
- Controle individual dos motores DC
- Controle de garra motorizada
- Controle de servo contínuo
- Integração com controle via gamepad
- Normalização automática da potência dos motores
- Telemetria em tempo real

---

## Tecnologias Utilizadas

- Java
- FTC SDK
- Programação aplicada à robótica
- Controle de hardware embarcado

---

## Estrutura do Sistema

O sistema realiza:

- leitura dos comandos do gamepad
- cálculo da movimentação do robô
- distribuição da potência entre os motores
- acionamento da garra e servo
- envio de informações via telemetria

---

## Controles

| Controle | Função |
|---|---|
| Analógicos do controle | Movimentação do robô |
| Botão A | Fechar/acionar garra |
| Botão B | Movimento reverso da garra |
| Botão Y | Acionar servo contínuo |
| Botão X | Reverter servo contínuo |
